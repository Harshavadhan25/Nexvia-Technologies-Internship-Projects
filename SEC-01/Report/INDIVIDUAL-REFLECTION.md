# Individual Reflection – SEC-01

## Project
Enterprise Red Team Simulation and Penetration Testing

## My Contribution
I worked on setting up and conducting a controlled penetration testing lab using Kali Linux and Metasploitable2 in VirtualBox. I performed network reconnaissance, service enumeration, web assessment, and selected security tests.

## Skills Gained
- Network scanning and service enumeration using Nmap
- Identifying exposed services and potential security weaknesses
- FTP and SMB anonymous access assessment
- Web directory listing and information disclosure testing
- Using Metasploit for controlled exploitation
- Collecting evidence and documenting findings
- Mapping findings to MITRE ATT&CK

## Challenges
Setting up the isolated lab environment and understanding the results of different network services were challenging. I also learned the importance of validating findings and maintaining clear evidence.

## Limitations
The project did not include a Windows Active Directory environment, BloodHound analysis, or lateral movement. These remain possible areas for future improvement.

## Learning Outcome
This project improved my practical understanding of penetration testing methodology, vulnerability assessment, evidence collection, and security reporting.

## Conclusion
The project provided valuable hands-on experience with red team tools and techniques and strengthened my foundation in cybersecurity.
