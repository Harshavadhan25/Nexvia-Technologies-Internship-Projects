# SEC-02: Security Operations Center (SOC) Build-Out

## Project Overview
A hands-on SOC monitoring implementation using Splunk Enterprise to collect, monitor, and analyze security events from Windows and Ubuntu systems.

## Activities
- Splunk Enterprise SIEM deployment
- Windows Sysmon event monitoring
- Windows Splunk Universal Forwarder configuration
- Ubuntu log forwarding
- Security event analysis and detection testing
- SOC monitoring dashboard creation
- Failed login alert configuration

## Tools
- Splunk Enterprise
- Splunk Universal Forwarder
- Windows Sysmon
- Ubuntu Server
- VirtualBox

## Dashboard
The dashboard includes:
- Windows failed login activity
- Ubuntu authentication activity
- PowerShell process activity
- Administrator group changes
- Network connection activity

## Deliverables
- SOC implementation report
- Evidence and screenshots
- Dashboard configuration
- Architecture documentation
- Project presentation
- Individual reflection
- Practical demonstration video

## Limitations
Suricata, Atomic Red Team, TheHive, Cortex, and Shuffle SOAR were not implemented in this version. The report documents the actual implementation and future improvements.
