# SEC-01: Enterprise Red Team Simulation and Penetration Testing

## Project Overview
A controlled penetration testing exercise using Kali Linux and Metasploitable2 in an isolated VirtualBox lab.

## Activities
- Network reconnaissance and Nmap scanning
- Service and version enumeration
- FTP and SMB anonymous access assessment
- Web directory and information disclosure testing
- Controlled UnrealIRCd exploitation
- Evidence collection and security findings
- MITRE ATT&CK mapping

## Tools
- Kali Linux
- Metasploitable2
- Nmap
- Metasploit Framework
- VirtualBox

## Deliverables
- Penetration testing report
- Evidence and screenshots
- Project presentation
- Individual reflection
- Practical demonstration video

## Limitations
The assessment did not include a Windows Active Directory environment, BloodHound analysis, or lateral movement. The report documents the actual testing scope and results.
