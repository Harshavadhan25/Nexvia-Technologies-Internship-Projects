# Nexvia Technologies – Cybersecurity Internship Projects

## Overview
This repository contains the two cybersecurity projects completed as part of the Nexvia Technologies Cybersecurity Internship.

## Project 1: SEC-01 – Enterprise Red Team Simulation and Penetration Testing
A controlled penetration testing assessment using Kali Linux and Metasploitable2 in an isolated VirtualBox environment.

**Key activities:**
- Network reconnaissance and service enumeration
- Vulnerability assessment
- FTP and SMB security testing
- Web information disclosure assessment
- Controlled exploitation and evidence collection
- MITRE ATT&CK mapping

**Tools:** Kali Linux, Metasploitable2, Nmap, Metasploit Framework, VirtualBox.

## Project 2: SEC-02 – Security Operations Center (SOC) Build-Out
A practical SOC monitoring implementation using Splunk Enterprise to collect and analyze security events from Windows and Ubuntu systems.

**Key activities:**
- Splunk Enterprise SIEM setup
- Windows Sysmon monitoring
- Windows and Ubuntu log forwarding
- Security event analysis and detection testing
- SOC dashboard creation
- Failed login alert configuration

**Tools:** Splunk Enterprise, Splunk Universal Forwarder, Sysmon, Ubuntu Server, VirtualBox.

## Repository Structure
- `SEC-01/` – Red Team and penetration testing project
- `SEC-02/` – SOC build-out project

Each project folder contains its own overview. Reports, evidence, screenshots, presentations, reflections, and demonstration recordings will be organized within the respective project folders.

## Important Note
The reports document the actual implementation scope, test results, limitations, and future improvements. Activities not implemented are not presented as completed.
